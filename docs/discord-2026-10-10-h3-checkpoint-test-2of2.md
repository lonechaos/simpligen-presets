**Worth knowing**

- Same seed, same card gives exactly the same video every time.
- None of the adult-oriented checkpoints had trouble with this fully clothed scene.

**Limits:** one seed and one scene, judged from still frames. We did not judge the audio. Treat it as first impressions, not a ranking.
